# Whisper 技术科普文档

## 一、Whisper 模型介绍

### 1.1 模型结构

Whisper 采用经典的 **Encoder-Decoder Transformer** 架构。

#### 整体架构图（ASCII）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              WHISPER 架构                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌─────────────┐                                                            │
│  │ Audio Input │  16kHz 采样率                                              │
│  │  (30 sec)   │                                                            │
│  └──────┬──────┘                                                            │
│         │                                                                   │
│         ▼                                                                   │
│  ┌─────────────────────────────────────┐                                    │
│  │     Log-Mel Spectrogram 提取        │                                    │
│  │  ┌─────────────────────────────┐   │                                    │
│  │  │ STFT (n_fft=400, hop=160)   │   │                                    │
│  │  │         ↓                   │   │                                    │
│  │  │ Mel Filterbank (80/128维)   │   │                                    │
│  │  │         ↓                   │   │                                    │
│  │  │ Log Transform               │   │                                    │
│  │  └─────────────────────────────┘   │                                    │
│  │  输出: [80/128, 3000] (30s×100fps)  │                                    │
│  └──────────────┬──────────────────────┘                                    │
│                 │                                                           │
│                 ▼                                                           │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                      AUDIO ENCODER                                   │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │ Conv1D Layer 1: (80→d_model), kernel=3, padding=1, GELU       │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                              ↓                                       │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │ Conv1D Layer 2: (d_model→d_model), kernel=3, stride=2, GELU   │  │   │
│  │  │ (下采样 2x: 3000 → 1500 帧)                                    │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                              ↓                                       │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │ + Sinusoidal Positional Embedding [1500, d_model]             │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                              ↓                                       │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │              Transformer Encoder Blocks × N_enc               │  │   │
│  │  │  ┌─────────────────────────────────────────────────────────┐  │  │   │
│  │  │  │ LayerNorm → Multi-Head Self-Attention → Residual        │  │  │   │
│  │  │  │     ↓                                                   │  │  │   │
│  │  │  │ LayerNorm → FFN (d→4d→d, GELU) → Residual               │  │  │   │
│  │  │  └─────────────────────────────────────────────────────────┘  │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                              ↓                                       │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │ LayerNorm (Post-LN)                                           │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │  输出: Audio Features [batch, 1500, d_model]                        │   │
│  └──────────────────────────────┬──────────────────────────────────────┘   │
│                                 │                                           │
│                                 │ Cross-Attention                           │
│                                 ▼                                           │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                       TEXT DECODER                                   │   │
│  │                                                                      │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │ Token Embedding [vocab_size, d_model]                         │  │   │
│  │  │ + Learned Positional Embedding [448, d_model]                 │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                              ↓                                       │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │              Transformer Decoder Blocks × N_dec               │  │   │
│  │  │  ┌─────────────────────────────────────────────────────────┐  │  │   │
│  │  │  │ LayerNorm → Masked Multi-Head Self-Attention → Residual │  │  │   │
│  │  │  │     ↓                                                   │  │  │   │
│  │  │  │ LayerNorm → Multi-Head Cross-Attention → Residual       │  │  │   │
│  │  │  │     ↓        (K,V from Encoder)                         │  │  │   │
│  │  │  │ LayerNorm → FFN (d→4d→d, GELU) → Residual               │  │  │   │
│  │  │  └─────────────────────────────────────────────────────────┘  │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │                              ↓                                       │   │
│  │  ┌───────────────────────────────────────────────────────────────┐  │   │
│  │  │ LayerNorm → Linear (共享 Token Embedding 权重) → Softmax      │  │   │
│  │  └───────────────────────────────────────────────────────────────┘  │   │
│  │  输出: Token Probabilities [batch, seq_len, vocab_size]             │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### Encoder Block 详细结构

```
输入 x [batch, 1500, d_model]
        │
        ▼
┌───────────────────────────────────────┐
│           LayerNorm                   │
└───────────────────┬───────────────────┘
                    │
                    ▼
┌───────────────────────────────────────┐
│     Multi-Head Self-Attention         │
│  ┌─────────────────────────────────┐  │
│  │ Q = x @ W_q  [d_model → d_model]│  │
│  │ K = x @ W_k  [d_model → d_model]│  │  (W_k 无 bias)
│  │ V = x @ W_v  [d_model → d_model]│  │
│  │                                 │  │
│  │ 分头: [batch, n_head, seq, d_k] │  │  d_k = d_model / n_head = 64
│  │                                 │  │
│  │ Attention = softmax(QK^T/√d_k)V │  │
│  │                                 │  │
│  │ Output = Concat(heads) @ W_o    │  │
│  └─────────────────────────────────┘  │
└───────────────────┬───────────────────┘
                    │
                    ▼
              x + Attention (残差连接)
                    │
                    ▼
┌───────────────────────────────────────┐
│           LayerNorm                   │
└───────────────────┬───────────────────┘
                    │
                    ▼
┌───────────────────────────────────────┐
│     Feed-Forward Network (FFN)        │
│  ┌─────────────────────────────────┐  │
│  │ Linear: d_model → 4*d_model     │  │
│  │ GELU 激活                        │  │
│  │ Linear: 4*d_model → d_model     │  │
│  └─────────────────────────────────┘  │
└───────────────────┬───────────────────┘
                    │
                    ▼
              x + FFN (残差连接)
                    │
                    ▼
输出 [batch, 1500, d_model]
```

#### Decoder Block 详细结构

```
输入 x [batch, seq_len, d_model], audio_features [batch, 1500, d_model]
        │
        ▼
┌───────────────────────────────────────┐
│           LayerNorm                   │
└───────────────────┬───────────────────┘
                    │
                    ▼
┌───────────────────────────────────────┐
│   Masked Multi-Head Self-Attention    │
│  ┌─────────────────────────────────┐  │
│  │ Q, K, V 均来自 x                 │  │
│  │ + Causal Mask (上三角 -inf)      │  │  防止看到未来 token
│  └─────────────────────────────────┘  │
└───────────────────┬───────────────────┘
                    │
              x + Self-Attn (残差)
                    │
                    ▼
┌───────────────────────────────────────┐
│           LayerNorm                   │
└───────────────────┬───────────────────┘
                    │
                    ▼
┌───────────────────────────────────────┐
│     Multi-Head Cross-Attention        │
│  ┌─────────────────────────────────┐  │
│  │ Q 来自 Decoder 隐状态            │  │
│  │ K, V 来自 Encoder 输出           │  │  ← 音频特征
│  │ (K, V 可缓存，推理时复用)         │  │
│  └─────────────────────────────────┘  │
└───────────────────┬───────────────────┘
                    │
              x + Cross-Attn (残差)
                    │
                    ▼
┌───────────────────────────────────────┐
│           LayerNorm                   │
└───────────────────┬───────────────────┘
                    │
                    ▼
┌───────────────────────────────────────┐
│     Feed-Forward Network (FFN)        │
└───────────────────┬───────────────────┘
                    │
              x + FFN (残差)
                    │
                    ▼
输出 [batch, seq_len, d_model]
```

#### 不同规模模型的结构参数

| 模型 | 参数量 | Encoder层数 | Decoder层数 | 隐藏维度 (d_model) | 注意力头数 | FFN维度 | 每头维度 |
|------|--------|-------------|-------------|-------------------|------------|---------|---------|
| tiny | 39M | 4 | 4 | 384 | 6 | 1536 | 64 |
| base | 74M | 6 | 6 | 512 | 8 | 2048 | 64 |
| small | 244M | 12 | 12 | 768 | 12 | 3072 | 64 |
| medium | 769M | 24 | 24 | 1024 | 16 | 4096 | 64 |
| large | 1550M | 32 | 32 | 1280 | 20 | 5120 | 64 |
| turbo | 809M | 32 | **4** | 1280 | 20 | 5120 | 64 |

**参数差异维度分析**：
- **层数（depth）**：tiny(4) → large(32)，8倍增长
- **隐藏维度（width）**：tiny(384) → large(1280)，约3.3倍增长
- **注意力头数**：随隐藏维度同步增加，保持每头维度固定为 64
- **FFN 维度**：始终为 4 × d_model（标准 Transformer 设计）
- **turbo 特殊性**：Encoder 保持 32 层，Decoder 剪枝至 4 层

### 1.2 借鉴的技术

#### 来自 NLP 领域

| 技术 | 来源 | 在 Whisper 中的应用 |
|------|------|---------------------|
| **Transformer** | Vaswani et al. (2017) "Attention Is All You Need" | 整体 Encoder-Decoder 架构 |
| **Seq2Seq** | Sutskever et al. (2014) | 序列到序列的生成范式 |
| **BPE Tokenizer** | GPT-2 (2019) | 多语言子词分词，词表大小 51865 |
| **Causal Masking** | GPT 系列 | Decoder 自回归生成时的因果掩码 |
| **Pre-LN** | 改进的 Transformer | LayerNorm 在 Attention/FFN 之前 |
| **Weight Tying** | Press & Wolf (2017) | Decoder 输出层与 Token Embedding 共享权重 |

#### 来自语音领域

| 技术 | 说明 |
|------|------|
| **Log-Mel Spectrogram** | 80维梅尔滤波器组（v3 升级为 128 维），模拟人耳听觉特性 |
| **30秒滑动窗口** | 借鉴传统 ASR 的分段处理，固定长度简化 batch 处理 |
| **16kHz 采样率** | 语音识别标准采样率，覆盖人声频率范围 |
| **SpecAugment 思想** | 训练时对频谱图做数据增强（未明确公开细节） |

#### 来自 CV 领域

| 技术 | 来源 | 应用 |
|------|------|------|
| **卷积下采样** | 类似 ViT 的 Patch Embedding | 2 层 Conv1D 将频谱图压缩为序列，stride=2 实现 2x 下采样 |
| **GELU 激活** | BERT/GPT | 替代 ReLU，更平滑的激活函数 |

### 1.4 支持的任务

Whisper 通过 **特殊 token 序列** 实现多任务统一：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        Whisper Token 序列格式                            │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  <|startoftranscript|> <|语言|> <|任务|> <|时间戳设置|> ...文本... <|endoftext|>
│                                                                         │
│  示例:                                                                   │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │ <|startoftranscript|><|zh|><|transcribe|><|notimestamps|>       │   │
│  │ 今天天气很好<|endoftext|>                                        │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  带时间戳:                                                               │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │ <|startoftranscript|><|zh|><|transcribe|><|0.00|>今天           │   │
│  │ <|0.50|>天气<|1.00|>很好<|1.50|><|endoftext|>                   │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

#### 任务类型详解

| 任务 | 输入 | 输出 | 特殊 Token |
|------|------|------|------------|
| **语音识别 (ASR)** | 任意语言音频 | 同语言文本 | `<|transcribe|>` |
| **语音翻译 (ST)** | 任意语言音频 | 英语文本 | `<|translate|>` |
| **语言识别 (LID)** | 音频 | 语言 token | 预测 `<|xx|>` |
| **语音活动检测 (VAD)** | 音频 | 有无人声 | `<|nospeech|>` |
| **时间戳对齐** | 音频 | 带时间戳文本 | `<|0.00|>` ~ `<|30.00|>` |

### 1.5 任务机制实现

#### 转录 vs 翻译的切换

```
┌─────────────────────────────────────────────────────────────────┐
│                    任务切换机制                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  输入: 中文语音 "今天天气很好"                                    │
│                                                                 │
│  转录任务 (Transcribe):                                          │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ Decoder 输入: <|startoftranscript|><|zh|><|transcribe|> │   │
│  │ Decoder 输出: 今天天气很好<|endoftext|>                  │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  翻译任务 (Translate):                                           │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ Decoder 输入: <|startoftranscript|><|zh|><|translate|>  │   │
│  │ Decoder 输出: The weather is nice today<|endoftext|>    │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  机制: 任务 token 作为条件，影响 Decoder 的生成分布               │
│  注意: 翻译任务仅支持 X → English，不支持其他目标语言             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 语种切换机制

```
┌─────────────────────────────────────────────────────────────────┐
│                    语言识别与切换                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  自动语言识别流程:                                               │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 1. Encoder 编码音频特征                                  │   │
│  │ 2. Decoder 输入 <|startoftranscript|>                   │   │
│  │ 3. 预测下一个 token 的概率分布                           │   │
│  │ 4. 在所有语言 token 上取 argmax                          │   │
│  │ 5. 得到语言: <|zh|>, <|en|>, <|ja|>, ...                │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  语言 token 列表 (部分):                                         │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ <|en|> 英语    <|zh|> 中文    <|ja|> 日语               │   │
│  │ <|ko|> 韩语    <|de|> 德语    <|fr|> 法语               │   │
│  │ <|es|> 西班牙语 <|ru|> 俄语   <|ar|> 阿拉伯语           │   │
│  │ ... 共 99 种语言                                        │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  强制指定语言:                                                   │
│  model.transcribe(audio, language="zh")                         │
│  → 跳过语言检测，直接使用 <|zh|>                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 混合语种（Code-Switching）

```
┌─────────────────────────────────────────────────────────────────┐
│                    混合语种处理                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Whisper 设计假设: 每个 30 秒片段为单一语言                       │
│                                                                 │
│  实际表现:                                                       │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 输入: "这个 project 的 deadline 是下周"                  │   │
│  │                                                         │   │
│  │ 可能输出 1: "这个 project 的 able 是下周" (音译错误)     │   │
│  │ 可能输出 2: "这个项目的截止日期是下周" (翻译替换)        │   │
│  │ 可能输出 3: "这个 project 的 deadline 是下周" (正确)     │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  原因:                                                          │
│  • 训练数据中混合语种样本较少                                    │
│  • 语言 token 条件化了整个序列的生成                             │
│  • BPE 分词器对混合语种处理不一致                                │
│                                                                 │
│  改进方案:                                                       │
│  • 使用 large 模型（更好的泛化能力）                             │
│  • 微调时加入混合语种数据                                        │
│  • 后处理纠错                                                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.6 English-only 模型

| 特性 | 多语言模型 | English-only 模型 |
|------|-----------|-------------------|
| **可用规模** | tiny ~ large | tiny.en ~ medium.en |
| **词表大小** | 51865 | 51864 (无多语言 token) |
| **英语性能** | 良好 | 略优（尤其 tiny/base） |
| **其他语言** | 支持 99 种 | 不支持 |
| **模型大小** | 标准 | 略小 |

**选择建议**：
- 纯英语场景：优先使用 `.en` 模型
- 多语言/不确定语言：使用多语言模型
- large 规模：仅有多语言版本

#### 方法二：LoRA 微调（Low-Rank Adaptation）

```bash
python find_tune/train_shanghai.py --finetune_method lora --lora_r 16 --lora_alpha 32
```

**LoRA 原理详解**：

LoRA 的核心思想是：预训练模型的权重更新矩阵 ΔW 是低秩的，可以分解为两个小矩阵的乘积。

```
┌─────────────────────────────────────────────────────────────────┐
│                    LoRA 数学原理                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  原始前向传播:                                                   │
│  h = W₀ · x                     (W₀ 是预训练权重，冻结)          │
│                                                                 │
│  LoRA 前向传播:                                                  │
│  h = W₀ · x + ΔW · x                                            │
│    = W₀ · x + (B · A) · x       (ΔW = B · A，低秩分解)           │
│    = W₀ · x + B · (A · x)                                       │
│                                                                 │
│  其中:                                                          │
│  • W₀ ∈ ℝ^(d×d)  : 原始权重矩阵，冻结不训练                      │
│  • A ∈ ℝ^(r×d)   : 降维矩阵，r << d                             │
│  • B ∈ ℝ^(d×r)   : 升维矩阵                                     │
│  • r             : LoRA rank，控制适配器容量                     │
│                                                                 │
│  参数量对比 (以 d=1024, r=16 为例):                              │
│  • 原始: d × d = 1,048,576                                      │
│  • LoRA: r × d + d × r = 32,768  (仅 3.1%)                      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**LoRA 在 Attention 层的注入位置**：

```
┌─────────────────────────────────────────────────────────────────┐
│              LoRA 注入到 Multi-Head Attention                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  输入 x [batch, seq, d_model]                                   │
│         │                                                       │
│         ▼                                                       │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                    Query 投影                            │   │
│  │  ┌───────────────┐     ┌───────────────┐                │   │
│  │  │   W_q (冻结)   │  +  │  B_q · A_q    │  ← LoRA 适配器  │   │
│  │  │  [d, d]       │     │ [d,r]·[r,d]   │                │   │
│  │  └───────────────┘     └───────────────┘                │   │
│  │  Q = (W_q + B_q·A_q) · x                                │   │
│  └─────────────────────────────────────────────────────────┘   │
│         │                                                       │
│         ▼                                                       │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                    Key 投影                              │   │
│  │  ┌───────────────┐     ┌───────────────┐                │   │
│  │  │   W_k (冻结)   │  +  │  B_k · A_k    │  ← LoRA 适配器  │   │
│  │  └───────────────┘     └───────────────┘                │   │
│  │  K = (W_k + B_k·A_k) · x                                │   │
│  └─────────────────────────────────────────────────────────┘   │
│         │                                                       │
│         ▼                                                       │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                    Value 投影                            │   │
│  │  ┌───────────────┐     ┌───────────────┐                │   │
│  │  │   W_v (冻结)   │  +  │  B_v · A_v    │  ← LoRA 适配器  │   │
│  │  └───────────────┘     └───────────────┘                │   │
│  │  V = (W_v + B_v·A_v) · x                                │   │
│  └─────────────────────────────────────────────────────────┘   │
│         │                                                       │
│         ▼                                                       │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │              Attention 计算 (不变)                       │   │
│  │  Attention(Q, K, V) = softmax(QK^T/√d_k) · V            │   │
│  └─────────────────────────────────────────────────────────┘   │
│         │                                                       │
│         ▼                                                       │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                    Output 投影                           │   │
│  │  ┌───────────────┐     ┌───────────────┐                │   │
│  │  │   W_o (冻结)   │  +  │  B_o · A_o    │  ← LoRA 适配器  │   │
│  │  └───────────────┘     └───────────────┘                │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**本项目 LoRA 配置详情**：

```python
# find_tune/train_shanghai.py 中的 LoRA 配置
from peft import LoraConfig, get_peft_model, TaskType

target_modules = [
    "q_proj",    # Query 投影层
    "v_proj",    # Value 投影层  
    "k_proj",    # Key 投影层
    "out_proj",  # Attention 输出投影层
    "fc1",       # FFN 第一层 (d → 4d)
    "fc2",       # FFN 第二层 (4d → d)
]

lora_config = LoraConfig(
    r=16,                          # LoRA rank
    lora_alpha=32,                 # 缩放因子 (实际缩放 = alpha/r = 2)
    target_modules=target_modules, # 注入位置
    lora_dropout=0.1,              # Dropout 防过拟合
    bias="none",                   # 不训练 bias
    task_type=TaskType.SEQ_2_SEQ_LM,
)
```

**LoRA 超参数详解**：

| 参数 | 作用 | 推荐值 | 说明 |
|------|------|--------|------|
| `r` (rank) | 控制适配器容量 | 8-64 | 越大表达能力越强，但参数越多 |
| `lora_alpha` | 缩放因子 | 2×r | 实际缩放 = alpha/r，通常设为 2 |
| `target_modules` | 注入位置 | q,k,v,o,fc1,fc2 | 覆盖 Attention 和 FFN |
| `lora_dropout` | 正则化 | 0.05-0.1 | 防止过拟合 |

**LoRA 参数量计算**：

```
以 Whisper medium 模型为例:
- d_model = 1024
- Encoder 层数 = 24, Decoder 层数 = 24
- 每层 Attention: 4 个投影矩阵 (Q, K, V, O)
- 每层 FFN: 2 个投影矩阵 (fc1, fc2)

每个 LoRA 适配器参数量 = 2 × r × d_model = 2 × 16 × 1024 = 32,768

总 LoRA 参数量:
= (24 + 24) × (4 + 2) × 32,768
= 48 × 6 × 32,768
= 9,437,184 (约 9.4M)

占比: 9.4M / 769M ≈ 1.2%
```

| 优点 | 缺点 |
|------|------|
| 参数效率高（仅训练 1-2%） | 表达能力受限于 rank |
| 显存占用低 | 需要 PEFT 库支持 |
| 可保存多个适配器切换任务 | 某些极端任务可能不够 |
| 训练速度快 | |
| 减少灾难性遗忘 | |

**代码实现**：

```python
def setup_partial_finetune(model, freeze_encoder_layers, freeze_decoder=False):
    # 冻结卷积层和位置编码
    for param in model.model.encoder.conv1.parameters():
        param.requires_grad = False
    for param in model.model.encoder.conv2.parameters():
        param.requires_grad = False
    for param in model.model.encoder.embed_positions.parameters():
        param.requires_grad = False
    
    # 冻结前 N 层 Encoder
    total_encoder_layers = len(model.model.encoder.layers)
    for i in range(min(freeze_encoder_layers, total_encoder_layers)):
        for param in model.model.encoder.layers[i].parameters():
            param.requires_grad = False
    
    # 可选：冻结 Decoder
    if freeze_decoder:
        for param in model.model.decoder.parameters():
            param.requires_grad = False
```

| 优点 | 缺点 |
|------|------|
| 保留底层通用声学特征 | 需要调参确定冻结层数 |
| 减少过拟合风险 | 不如 LoRA 灵活 |
| 显存占用适中 | 无法保存独立适配器 |
| 无需额外库 | |

### 4.1 关键超参数

```python
# 音频处理参数
SAMPLE_RATE = 16000          # 采样率 (Hz)
N_FFT = 400                  # FFT 窗口大小 (25ms @ 16kHz)
HOP_LENGTH = 160             # 帧移 (10ms @ 16kHz)
CHUNK_LENGTH = 30            # 音频片段长度 (秒)
N_MELS = 80                  # Mel 滤波器数 (v3 为 128)

# 频谱图尺寸计算
# 30秒音频 @ 16kHz = 480,000 采样点
# 帧数 = (480,000 - 400) / 160 + 1 ≈ 3000 帧
# 经过 stride=2 下采样后 = 1500 帧

# 模型参数
N_TEXT_CTX = 448             # 最大文本 token 长度
N_AUDIO_CTX = 1500           # 音频序列长度 (30s / 20ms)
```

### 4.3 时间戳机制

```
┌─────────────────────────────────────────────────────────────────┐
│                    时间戳生成机制                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  时间戳 Token:                                                   │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ <|0.00|>, <|0.02|>, <|0.04|>, ..., <|29.98|>, <|30.00|> │   │
│  │                                                         │   │
│  │ • 共 1501 个时间戳 token                                │   │
│  │ • 精度: 20ms (与帧移 10ms × 2 对应)                     │   │
│  │ • 范围: 0.00s ~ 30.00s                                  │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  生成示例:                                                       │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ <|0.00|> Hello <|0.50|> world <|1.00|>                  │   │
│  │                                                         │   │
│  │ 解析:                                                   │   │
│  │ • "Hello" 出现在 0.00s ~ 0.50s                          │   │
│  │ • "world" 出现在 0.50s ~ 1.00s                          │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  词级对齐 (通过 Cross-Attention):                                │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 1. 提取 Decoder 的 Cross-Attention 权重                 │   │
│  │ 2. 对于每个生成的 token，找到注意力最高的音频帧         │   │
│  │ 3. 将帧索引转换为时间: time = frame_idx × 0.02s         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 五、评估指标详解

### 5.1 语音识别指标

#### WER (Word Error Rate，词错误率)

**定义**：衡量 ASR 系统输出与参考文本之间的差异，基于编辑距离。

```
┌─────────────────────────────────────────────────────────────────┐
│                    WER 计算公式                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│                    S + D + I                                    │
│         WER = ─────────────── × 100%                            │
│                      N                                          │
│                                                                 │
│  其中:                                                          │
│  • S (Substitutions): 替换错误数                                │
│  • D (Deletions): 删除错误数                                    │
│  • I (Insertions): 插入错误数                                   │
│  • N: 参考文本的总词数                                          │
│                                                                 │
│  注意: WER 可以超过 100% (当插入错误很多时)                      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**计算示例**：

```
参考文本 (Reference): "the cat sat on the mat"
预测文本 (Hypothesis): "a cat sit on mat"

对齐结果:
┌─────────────────────────────────────────────────────────────────┐
│  REF:  the   cat   sat   on   the   mat                        │
│  HYP:  a     cat   sit   on   -     mat                        │
│        ↓           ↓          ↓                                 │
│        S           S          D                                 │
│  (替换)       (替换)     (删除)                                 │
└─────────────────────────────────────────────────────────────────┘

S = 2 (the→a, sat→sit)
D = 1 (the 被删除)
I = 0
N = 6

WER = (2 + 1 + 0) / 6 × 100% = 50%
```

**Python 计算代码**：

```python
import jiwer

reference = "the cat sat on the mat"
hypothesis = "a cat sit on mat"

# 使用 jiwer 库计算
wer = jiwer.wer(reference, hypothesis)
print(f"WER: {wer * 100:.2f}%")  # 输出: WER: 50.00%

# 获取详细信息
measures = jiwer.compute_measures(reference, hypothesis)
print(f"Substitutions: {measures['substitutions']}")
print(f"Deletions: {measures['deletions']}")
print(f"Insertions: {measures['insertions']}")
```

#### CER (Character Error Rate，字符错误率)

**定义**：与 WER 类似，但在字符级别计算。

```
                    S_char + D_char + I_char
         CER = ─────────────────────────────── × 100%
                         N_char

适用场景:
• 中文、日文等无空格分词的语言
• 需要更细粒度评估时
• 词边界不明确的语言
```

**WER vs CER 选择**：

| 语言类型 | 推荐指标 | 原因 |
|----------|----------|------|
| 英语、德语等 | WER | 有明确词边界 |
| 中文、日文 | CER | 无空格分词 |
| 韩语 | 两者皆可 | 有空格但字符也有意义 |
| 混合语言 | 视情况而定 | 需要统一标准 |

### 5.2 翻译指标

#### BLEU (Bilingual Evaluation Understudy)

**定义**：衡量机器翻译与参考翻译之间的 n-gram 重叠度。

```
┌─────────────────────────────────────────────────────────────────┐
│                    BLEU 计算公式                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  BLEU = BP × exp(∑(wₙ × log(pₙ)))                               │
│                  n=1 to N                                       │
│                                                                 │
│  其中:                                                          │
│  • BP (Brevity Penalty): 简短惩罚                               │
│    BP = 1                    if c > r                           │
│    BP = exp(1 - r/c)         if c ≤ r                           │
│    (c = 候选长度, r = 参考长度)                                  │
│                                                                 │
│  • pₙ: n-gram 精确率                                            │
│    pₙ = (匹配的 n-gram 数) / (候选文本的 n-gram 总数)            │
│                                                                 │
│  • wₙ: 权重 (通常 w₁=w₂=w₃=w₄=0.25)                             │
│                                                                 │
│  BLEU-4: 使用 1-gram 到 4-gram 的几何平均                        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**计算示例**：

```python
from sacrebleu import corpus_bleu

references = [["The weather is nice today"]]
hypothesis = ["The weather is good today"]

bleu = corpus_bleu(hypothesis, references)
print(f"BLEU: {bleu.score:.2f}")  # 输出: BLEU: 51.15
```

### 5.3 评估中的常见坑

#### 坑 1：文本归一化不一致

```
┌─────────────────────────────────────────────────────────────────┐
│                    文本归一化问题                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  问题示例:                                                       │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 参考: "It's 10 o'clock."                                │   │
│  │ 预测: "it is ten oclock"                                │   │
│  │                                                         │   │
│  │ 未归一化 WER: 很高 (几乎全错)                           │   │
│  │ 归一化后 WER: 可能为 0% (语义相同)                      │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  常见归一化操作:                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 1. 大小写统一 (通常转小写)                              │   │
│  │ 2. 标点符号移除                                         │   │
│  │ 3. 数字转文字 ("10" → "ten")                            │   │
│  │ 4. 缩写展开 ("it's" → "it is")                          │   │
│  │ 5. 多余空格移除                                         │   │
│  │ 6. Unicode 归一化 (NFKC)                                │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  Whisper 内置归一化器:                                           │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ from whisper.normalizers import EnglishTextNormalizer   │   │
│  │ normalizer = EnglishTextNormalizer()                    │   │
│  │ normalized = normalizer(text)                           │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**正确做法**：

```python
from whisper.normalizers import EnglishTextNormalizer, BasicTextNormalizer
import jiwer

# 英语使用 EnglishTextNormalizer
english_normalizer = EnglishTextNormalizer()

# 其他语言使用 BasicTextNormalizer
basic_normalizer = BasicTextNormalizer()

def compute_wer_normalized(reference, hypothesis, language="en"):
    if language == "en":
        normalizer = english_normalizer
    else:
        normalizer = basic_normalizer
    
    ref_normalized = normalizer(reference)
    hyp_normalized = normalizer(hypothesis)
    
    return jiwer.wer(ref_normalized, hyp_normalized)
```

#### 坑 2：中文分词问题

```
┌─────────────────────────────────────────────────────────────────┐
│                    中文分词对 WER 的影响                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  问题:                                                          │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 参考: "今天天气很好"                                     │   │
│  │ 预测: "今天天气很好"                                     │   │
│  │                                                         │   │
│  │ 不分词直接计算 WER:                                     │   │
│  │ • 整句作为一个"词"                                      │   │
│  │ • 任何差异都是 100% 错误                                │   │
│  │                                                         │   │
│  │ 分词后计算 WER:                                         │   │
│  │ • "今天 天气 很 好" vs "今天 天气 很 好"                │   │
│  │ • 可以计算词级别的错误                                  │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  解决方案:                                                       │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 方案 1: 使用 CER (字符错误率)                           │   │
│  │ 方案 2: 使用分词工具 (jieba, pkuseg)                    │   │
│  │ 方案 3: 字符间加空格 (简单但粗糙)                       │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**中文评估代码**：

```python
import jieba
import jiwer

def compute_chinese_wer(reference, hypothesis):
    """使用 jieba 分词后计算 WER"""
    ref_words = " ".join(jieba.cut(reference))
    hyp_words = " ".join(jieba.cut(hypothesis))
    return jiwer.wer(ref_words, hyp_words)

def compute_chinese_cer(reference, hypothesis):
    """计算 CER (推荐用于中文)"""
    # 移除空格，按字符计算
    ref_chars = " ".join(list(reference.replace(" ", "")))
    hyp_chars = " ".join(list(hypothesis.replace(" ", "")))
    return jiwer.wer(ref_chars, hyp_chars)  # 字符级别的 "WER" 就是 CER
```

#### 坑 4：幻觉 (Hallucination) 检测

```
┌─────────────────────────────────────────────────────────────────┐
│                    Whisper 幻觉问题                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  什么是幻觉:                                                     │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ • 模型生成音频中不存在的内容                            │   │
│  │ • 常见于静音片段、背景噪声                              │   │
│  │ • 可能重复生成相同内容                                  │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  示例:                                                          │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 输入: [静音 5 秒]                                       │   │
│  │ 输出: "Thank you for watching. Please subscribe."       │   │
│  │       (完全是幻觉，音频中没有这些内容)                  │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  检测方法:                                                       │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 1. 检查 no_speech_prob (无语音概率)                     │   │
│  │    if segment.no_speech_prob > 0.6:                     │   │
│  │        # 可能是幻觉                                     │   │
│  │                                                         │   │
│  │ 2. 检查 compression_ratio (压缩比)                      │   │
│  │    if segment.compression_ratio > 2.4:                  │   │
│  │        # 可能有重复内容                                 │   │
│  │                                                         │   │
│  │ 3. 检查 avg_logprob (平均对数概率)                      │   │
│  │    if segment.avg_logprob < -1.0:                       │   │
│  │        # 模型不确定，可能是幻觉                         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 5.4 评估指标汇总

| 指标 | 任务 | 范围 | 越低越好? | 适用语言 |
|------|------|------|-----------|----------|
| **WER** | ASR | 0% ~ ∞ | ✅ | 英语等有空格语言 |
| **CER** | ASR | 0% ~ ∞ | ✅ | 中文、日文等 |
| **BLEU** | 翻译 | 0 ~ 100 | ❌ (越高越好) | 所有语言 |
| **RTF** | 速度 | 0 ~ ∞ | ✅ | - |
| **Latency** | 速度 | 0 ~ ∞ (ms) | ✅ | - |

**RTF (Real-Time Factor) 说明**：

```
RTF = 处理时间 / 音频时长

RTF < 1: 快于实时 (可用于实时转录)
RTF = 1: 实时
RTF > 1: 慢于实时

示例:
• 处理 10 秒音频用了 1 秒 → RTF = 0.1 (10x 实时)
• 处理 10 秒音频用了 10 秒 → RTF = 1.0 (实时)
• 处理 10 秒音频用了 20 秒 → RTF = 2.0 (0.5x 实时)
```
